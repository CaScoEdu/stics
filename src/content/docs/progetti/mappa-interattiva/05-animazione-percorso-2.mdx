## L'Algoritmo di Dijkstra (`dijkstra.js`)
<Aside type="tip" title="Come funziona Dijkstra?">
- L'algoritmo parte da un nodo di origine e imposta la distanza iniziale verso di esso a `0`, e verso tutti gli altri nodi a `Infinito (∞)`. 
- Esplora progressivamente i nodi vicini non ancora visitati, aggiornando il cammino più breve registrato fino a raggiungere il nodo di destinazione.
</Aside>
Separiamo la logica algoritmica creandola all'interno di un file dedicato, `dijkstra.js`:

```javascript title="dijkstra.js"
 /**
 * Algoritmo di Dijkstra per trovare il percorso minimo su un grafo pesato
 */
function calcolaDijkstra(grafo, inizio, fine) {
  if (!grafo || !Object.hasOwn(grafo, inizio) || !Object.hasOwn(grafo, fine)) {
    return [];
  }

  const distanze = {};
  const precedenti = {};
  const nodiNonVisitati = new Set();

  // Inizializzazione delle distanze
  Object.keys(grafo).forEach(nodo => {
    distanze[nodo] = Infinity;
    precedenti[nodo] = null;
    nodiNonVisitati.add(nodo);
  });
  distanze[inizio] = 0;

  while (nodiNonVisitati.size > 0) {
    // Trova il nodo non visitato con la distanza minore
    let nodoCorrente = null;
    nodiNonVisitati.forEach(nodo => {
      if (nodoCorrente === null || distanze[nodo] < distanze[nodoCorrente]) {
        nodoCorrente = nodo;
      }
    });

    if (distanze[nodoCorrente] === Infinity || nodoCorrente === fine) break;

    nodiNonVisitati.delete(nodoCorrente);

    // Aggiorna le distanze dei vicini
    const vicini = grafo[nodoCorrente] || {};
    for (let vicino in vicini) {
      if (nodiNonVisitati.has(vicino)) {
        let nuovaDistanza = distanze[nodoCorrente] + vicini[vicino];
        if (nuovaDistanza < distanze[vicino]) {
          distanze[vicino] = nuovaDistanza;
          precedenti[vicino] = nodoCorrente;
        }
      }
    }
  }

  // Ricostruzione del percorso a ritroso
  const percorso = [];
  let at = fine;
  while (at !== null && at !== undefined) {
    percorso.unshift(at);
    at = precedenti[at];
  }

  return percorso[0] === inizio ? percorso : [];
}
```

## Aggiornamento di `script.js`

Panoramica delle funzioni di logica e tracciamento
-   `aggiornaEvidenziazione()` (aggiornata):

    È il vero e proprio "motore centrale" dell'interazione. 
    Si attiva ogni volta che l'utente seleziona una 
    partenza o una destinazione:
    - ripulisce la mappa da vecchi segni,
    - applica le classi visive ai menu e agli edifici,
    - carica in modo asincrono il file `grafo.json` tramite `fetch()`, 
    - invoca l'algoritmo di **Dijkstra** per calcolare il percorso minimo e infine comanda il disegno della linea.

- `selezionaDaMappa(idEdificio)`:

    Permette all'utente di interagire direttamente cliccando sugli edifici della mappa SVG anziché usare i menu a tendina. Gestisce la selezione in modo "intelligente": il primo clic imposta la Partenza, il secondo la Destinazione, e i successivi ripartono da capo azzerando la scelta precedente.

- `ottieniCoordinateNodo(idNodo)`:

    Una funzione di supporto geometrico fondamentale. 
    Interroga il DOM della mappa SVG per trovare l'elemento 
    corrispondente a un determinato ID 
    (che si tratti di un cerchio elementi con tag `<circle>` 
    o di un rettangolo `<rect>`), 
    ne legge gli attributi posizionali e
    ne calcola il centro esatto, 
    restituendo le coordinate x,y pronte per essere tracciate.

- `disegnaPercorsoAnimato(nodi)`:

    Prende l'array di ID dei nodi calcolato da Dijkstra, converte ciascuno in coordinate reali usando la funzione precedente e crea dinamicamente un elemento grafico SVG restituendo un tag `<polyline>`. Lo inserisce con precisione nel DOM (esattamente sotto il layer degli edifici) per mostrare visivamente la strada da percorrere sulla mappa.

- `rimuoviSelezioniPrecedenti()`:

    La funzione di pulizia (reset). Prima di calcolare e mostrare un nuovo percorso, si occupa di rimuovere le classi CSS di evidenziazione dai vecchi edifici selezionati e di eliminare dal DOM l'eventuale polilinea disegnata in precedenza, evitando sovrapposizioni grafiche.

<AsideTip title="Ottimizzazione dei Layer SVG">
Inseriremo il percorso dinamico tra il layer delle strade e quello degli edifici usando insertBefore, così la linea passerà sotto i locali senza coprire le etichette di testo!
</AsideTip>

## Stile Serpentina in `style.css`

Aggiungi in fondo al file queste nuove regole CSS:

```diff lang="css" title="style.css"
+/* Stile per la linea del percorso dinamico (Serpentina in movimento) */
+.percorso-animato {
+  fill: none;
+  stroke: #0284c7;
+  stroke-width: 6;
+  stroke-linecap: round;
+  stroke-linejoin: round;
+  stroke-dasharray: 12, 12;
+  animation: serpentina 1s linear infinite;
+  filter: drop-shadow(0px 0px 6px rgba(2, 132, 199, 0.6));
+}
+
+@keyframes serpentina {
+  from {
+    stroke-dashoffset: 24;
+  }
+  to {
+    stroke-dashoffset: 0;
+  }
+}

```
<AsideNote title="🐍 l'effetto serpentina">

L'effetto "serpentina" (o effetto scia in movimento) si ottiene sfruttando una tecnica intelligente basata sulla manipolazione dei tratti di una linea SVG tramite CSS.

Ecco come funziona in sintesi:

1. `stroke-dasharray: 12, 12;`: Questa proprietà trasforma una linea continua in un tratteggio regolare, alternando segmenti pieni di 12 pixel e spazi vuoti di 12 pixel (per una lunghezza totale del pattern pari a 24 pixel).

2. `stroke-dashoffset`: Questa proprietà determina il punto di partenza da cui inizia il tratteggio lungo la linea.

3. L'animazione `@keyframes`: facendo scorrere ciclicamente il valore di `stroke-dashoffset` da `24` fino a `0` in modo lineare e continuo (`infinite`), i trattini si spostano in avanti lungo tutto il percorso.

All'occhio umano, questo scorrimento continuo dei trattini crea la tipica illusione ottica di un flusso in movimento (stile "marcia delle formiche" o percorso animato del navigatore).
</AsideNote>

## Riepilogo

<KeyConcepts>
- [`grafo.json`](https://it.wikipedia.org/wiki/Grafo): rappresenta la rete del campus con nodi e archi pesati; i pesi indicano distanze o costi di percorrenza.
- [Algoritmo di Dijkstra](https://it.wikipedia.org/wiki/Algoritmo_di_Dijkstra): trova il percorso minimo tra partenza e destinazione in un grafo con pesi non negativi.
- [`dijkstra.js`](https://developer.mozilla.org/it/docs/Web/JavaScript/Guide/Modules): contiene l'algoritmo per calcolare il percorso minimo, separandolo dalla logica dell'interfaccia.
- [`fetch()`](https://developer.mozilla.org/it/docs/Web/API/Fetch_API/Using_Fetch) e [`async` / `await`](https://developer.mozilla.org/it/docs/Web/JavaScript/Reference/Statements/async_function): caricano `grafo.json` in modo asincrono prima del calcolo del percorso.
- [Coordinate SVG](https://developer.mozilla.org/it/docs/Web/SVG/Attribute): gli attributi `cx`, `cy`, `x` e `y` consentono di ricavare le posizioni dei nodi sulla mappa.
- [`<polyline>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Element/polyline) e [animazioni CSS](https://developer.mozilla.org/it/docs/Web/CSS/CSS_animations/Using_CSS_animations): disegnano e animano la serpentina del percorso.
- [`classList`](https://developer.mozilla.org/it/docs/Web/API/Element/classList): applica o rimuove le classi di evidenziazione per partenza e destinazione.
</KeyConcepts>
