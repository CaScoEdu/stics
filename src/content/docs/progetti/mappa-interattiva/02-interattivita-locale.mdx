## Creazione del file `script.js` e uso di `document.getElementById()`

Crea un nuovo file denominato `script.js` nella cartella principale del progetto.

Al suo interno inseriremo la funzione che sfrutta `document.getElementById()`
per recuperare l'elemento SVG corrispondente all'edificio scelto e applicargli la classe `.attivo`:

```javascript title="script.js"
// Funzione invocata al cambio del menu a tendina
function evidenziaEdificioDaMenu() {
    rimuoviSelezionePrecedente();
    const selectMenu = document.getElementById("select-edificio");
    const idSelezionato = selectMenu.value;
    if (idSelezionato) {
        // sfruttiamo getElementById per trovare l'elemento SVG nel DOM
        const elementoEdificio = document.getElementById(idSelezionato);
        if (elementoEdificio) {
            elementoEdificio.classList.add("attivo");
        }
    }
}

// Funzione invocata cliccando direttamente un edificio sulla mappa SVG
function selezionaDaMappa (idEdificio) {
    const selectMenu = document.getElementById("select-edificio");
    selectMenu.value = idEdificio;
    evidenziaEdificioDaMenu();
}

// Funzione di servizio per pulire la selezione precedente
function rimuoviSelezionePrecedente() {
    const edificioAttivo = document.querySelector(".attivo");
    if (edificioAttivo) {
        edificioAttivo.classList.remove("attivo");
    }
}
```

<AsideNote title="Spiegazione dello script">
Lo script gestisce la selezione degli edifici in entrambe le modalità.
- Quando cambia il menu, `evidenziaEdificioDaMenu()` rimuove prima l’evidenziazione precedente, legge l’`id` selezionato e cerca nel DOM l’elemento SVG corrispondente con `document.getElementById()`. 
- Se lo trova, gli aggiunge la classe CSS `.attivo`, che applica l’effetto visivo definito in `style.css`.
- Cliccando un edificio sulla mappa, `selezionaDaMappa(idEdificio)` aggiorna il valore del menu e richiama la stessa funzione, così menu e mappa restano sincronizzati. `rimuoviSelezionePrecedente()` cerca l’elemento con classe `.attivo` e la rimuove: in questo modo viene evidenziato un solo edificio alla volta.
</AsideNote>

## Aggiunta dell'interattività in index.html

Per rendere la mappa interattiva nella seconda lezione, modifichiamo il file `index.html` inserendo un pannello di controllo con un menu a tendina, collegando gli eventi di click agli edifici e includendo lo script esterno.

<Steps>
1. #### Inserimento del pannello di controllo con il menu a tendina (`<select>`)
    Aggiungi il pannello di controllo subito prima del tag `<svg>`.
    :::caution
    Inserisci le opzioni (`<option>`) in base agli edifici che hai effettivamente creato nel tuo progetto.
    :::

    ```diff lang="html" title="index.html"
    <h1>🗺️ Mappa del Campus Universitario</h1>
    + 
    + <!-- PANNELLO DI CONTROLLO CON MENU A TENDINA -->
    + <div style="margin-bottom: 15px; background: white; padding: 10px; border-radius: 8px; border: 1px solid #cbd5e1;">
    +   <label for="select-edificio"><strong>🔍 Evidenzia Edificio:</strong></label>
    +   <select id="select-edificio" onchange="evidenziaEdificioDaMenu()" style="padding: 6px; border-radius: 4px; border: 1px solid #0284c7;">
    +     <option value="">-- Seleziona una destinazione --</option>
    +     <option value="edificio-uffici">Uffici Amministrativi</option>
    +     <!-- TODO: Aggiungi qui gli altri edifici personalizzati del tuo campus (es. Aule, Laboratori, ecc.) -->
    +   </select>
    + </div>
    
    <svg viewBox="0 0 800 600" width="800" height="600" xmlns="http://www.w3.org/2000/svg">
    ```
2. #### Aggiunta degli eventi onclick sugli edifici SVG
    Per permettere a ciascun edificio di rispondere al click del mouse, 
    collega l'attributo `onclick="selezionaDaMappa(...)"` ai gruppi `<g>` 
    dei singoli edifici all'interno di `<g id="layer-edifici">`.
    ```diff lang="html" title="index.html"
        <!-- LAYER 3: CAMPUS BUILDINGS -->
        <g id="layer-edifici">
    -       <g id="edificio-uffici">
    +       <!-- Aggiungi l'attributo onclick collegato alla funzione JavaScript -->
    +       <g id="edificio-uffici" onclick="selezionaDaMappa('edificio-uffici')">
            <rect x="70" y="80" width="100" height="140" fill="#1e3a8a" rx="6" />
            <text x="120" y="150" class="label">Uffici</text>
            </g>
            
    -       <!-- Ripeti per gli altri edifici... -->
    +       <!-- TODO: Estendi l'attributo onclick="selezionaDaMappa('id-edificio')" a tutti gli altri edifici del tuo SVG -->
        </g>
    ```
3. #### Collegamento del file JavaScript esterno
    Infine, appena prima della chiusura del corpo della pagina (`</body>`),
    inserisci il richiamo al file `script.js` che conterrà la logica di controllo.
    ```diff lang="html" title="index.html"

            </g>
        </g>
    </svg>
    + 
    + <!-- Collegamento al file JavaScript esterno -->
    + <script src="script.js"></script>

    </body>
    </html>
    ```

</Steps>

## Riepilogo

<KeyConcepts>
- [`<select>` e `<option>`](https://it.wikipedia.org/wiki/HTML): creano un menu a tendina per scegliere un edificio della mappa.
- [Eventi JavaScript](https://it.wikipedia.org/wiki/JavaScript): `onchange` intercetta la scelta nel menu e `onclick` il clic su un edificio SVG.
- [`document.getElementById()`](https://developer.mozilla.org/it/docs/Web/API/Document/getElementById): recupera dal DOM l'edificio identificato dal valore selezionato.
- [`classList`](https://developer.mozilla.org/it/docs/Web/API/Element/classList): aggiunge o rimuove la classe `attivo` per evidenziare l'edificio selezionato.
- [`script.js`](https://developer.mozilla.org/it/docs/Web/JavaScript): contiene la logica dell'interazione ed è collegato alla pagina HTML.
- [CSS](https://it.wikipedia.org/wiki/CSS): definisce l'effetto hover e lo stile di evidenziazione della classe `.attivo`.
</KeyConcepts>
