## 2. Aggiornamento di `style.css` (Effetti Hover e Classe `attivo`)

<Icon name="seti:css" size="2rem" label="css" color="DeepSkyBlue" />

Aggiungiamo in fondo al tuo file `style.css` le regole visive per il cursore al
passaggio del mouse e l'effetto di evidenziazione (bordo giallo e bagliore)
quando un edificio viene selezionato:

```css
//style.css
/* Effetto hover su tutti i gruppi edificio */
#layer-edifici > g {
  cursor: pointer;
  transition: opacity 0.2s ease;
}
#layer-edifici > g:hover {
  opacity: 0.85;
}
/* Stile applicato all'edificio SELEZIONATO tramite JS */
.attivo rect {
  stroke: #facc15 !important; /* Giallo acceso */
  stroke-width: 5px !important;
  filter: drop-shadow (0px 0px 10px #facc15);
}
```

## 2. Creazione del file `script.js` e uso di `document.getElementById()`

<Icon
  name="seti:javascript"
  size="2rem"
  label="javascript"
  color="DeepSkyBlue"
/>

Crea un nuovo file denominato `script.js` nella cartella principale del progetto.

Al suo interno inseriremo la funzione che sfrutta `document.getElementById()`
per recuperare l'elemento SVG corrispondente all'edificio scelto e applicargli la classe `.attivo`:

```javascript
//script.js
// Funzione invocata al cambio del menu a tendina
function evidenziaEdificioDaMenu() {
    rimuoviSelezione Precedente();
    const selectMenu = document.getElementById("select-edificio");
    const idSelezionato = selectMenu.value;
    if (idSelezionato) {
        // sfruttiamo getElementById per trovare l'elemento SVG nel DOM
        const elementoEdificio = document.getElementById(idSelezionato);
        if (elementoEdificio) {
            elementoEdificio.classList.add("attivo");
        }
    }
}

// Funzione invocata cliccando direttamente un edificio sulla mappa SVG
function selezionaDaMappa (idEdificio) {
    const selectMenu = document.getElementById("select-edificio");
    selectMenu.value = idEdificio;
    evidenziaEdificioDaMenu();
}

// Funzione di servizio per pulire la selezione precedente
function rimuovi SelezionePrecedente() {
    const edificioAttivo = document.querySelector(".attivo");
    if (edificioAttivo) {
        edificioAttivo.classList.remove("attivo");
    }
}
```

## 3. Aggiornamento di `index.html` (Menu e Collegamento JS)
<Icon
  name="seti:html"
  size="2rem"
  label="html"
  color="DeepSkyBlue"
/>

Modifichiamo il file `index.html` inserendo un pannello di controllo con il menu a tendina `<select>`, aggiungendo gli
attributi `onclick` ai vari edifici SVG e collegando il file `script.js` prima della chiusura del `body`:

```html
//index.html
<!DOCTYPE html>
<html lang="it">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mappa Campus Interattiva - Lezione 2</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>

  <h1>🗺️ Mappa del Campus Interattiva</h1>

  <!-- PANNELLO DI CONTROLLO CON MENU A TENDINA -->
  <div style="margin-bottom: 15px; background: white; padding: 10px; border-radius: 8px; border: 1px solid #cbd5e1;">
    <label for="select-edificio"><strong>🔍 Evidenzia Edificio:</strong></label>
    <select id="select-edificio" onchange="evidenziaEdificioDaMenu()" style="padding: 6px; border-radius: 4px; border: 1px solid #0284c7;">
      <option value="">-- Seleziona una destinazione --</option>
      <option value="edificio-uffici">Uffici Amministrativi</option>
      <option value="edificio-aule">Edificio Aule</option>
      <option value="edificio-laboratori">Laboratori</option>
      <option value="edificio-mensa">Mensa Campus</option>
      <option value="edificio-palestra">Palestra</option>
    </select>
  </div>

  <svg viewBox="0 0 800 600" width="800" height="600" xmlns="http://www.w3.org/2000/svg">
    
    <g id="layer-terreno">
      <rect x="0" y="0" width="800" height="600" fill="#7ec850" />
    </g>

    <g id="layer-percorsi">
      <rect x="50" y="270" width="700" height="60" fill="#d1d5db" rx="4" />
      <rect x="180" y="80" width="50" height="440" fill="#d1d5db" rx="4" />
      <rect x="570" y="80" width="50" height="440" fill="#d1d5db" rx="4" />
    </g>

    <!-- Aggiunta degli eventi onclick collegati a JavaScript -->

      <g id="edificio-uffici" onclick="selezionaDaMappa('edificio-uffici')">
```
