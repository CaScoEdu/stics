## 2. Definizione del Grafo con gli Snodi (grafo.json)
Aggiorniamo il file grafo.json passando dai collegamenti diretti
 tra edifici alla rete strutturata tramite gli snodi.   
 Ricordiamo le proprietà fondamentali di un Grafo Non Orientato e Pesato:
 - Non orientato: I collegamenti (archi) sono bidirezionali. 
    Se lo snodo $A$ è collegato allo snodo $B$ con un certo peso, 
    la stessa percorrenza vale in entrambi i versi.   
- Pesato: Ogni arco ha un costo numerico (il peso, es. metri o secondi), 
    utilizzato da Dijkstra per calcolare il percorso minimo.

Ecco un frammento corretto di grafo.json che modella il passaggio dagli uffici agli incroci tramite gli snodi:
```json title="grafo.json"
{
  "edificio-uffici": { "snodo-uffici": 30 },
  "snodo-uffici": {
    "edificio-uffici": 30,
    "snodo-incrocio-ovest": 100
  },
  "snodo-incrocio-ovest": {
    "snodo-uffici": 100,
    "snodo-aule": 130,
    "snodo-incrocio-est": 390
  }
}
```

## 3. L'Algoritmo di Dijkstra (`dijkstra.js`)

<Aside type="note" title="Come funziona Dijkstra?">
L'algoritmo parte da un nodo di origine ed imposta la distanza iniziale verso di esso a 0, e verso tutti gli altri nodi a Infinito ($\infty$). Esplora progressivamente i nodi vicini non ancora visitati, aggiornando il cammino più breve registrato fino a raggiungere il nodo di destinazione[cite: 13].
</Aside>

Separiamo la logica algoritmica creandola all'interno di un file dedicato `dijkstra.js`[cite: 13]:

```javascript title="dijkstra.js"
/**
 * Algoritmo di Dijkstra per trovare il percorso minimo su un grafo pesato
 */
function calcolaDijkstra(grafo, inizio, fine) {
  const distanze = {};
  const precedenti = {};
  const nodiNonVisitati = new Set();

  // Inizializzazione delle distanze
  Object.keys(grafo).forEach(nodo => {
    distanze[nodo] = Infinity;
    precedenti[nodo] = null;
    nodiNonVisitati.add(nodo);
  });

  distanze[inizio] = 0;

  while (nodiNonVisitati.size > 0) {
    // Trova il nodo non visitato con la distanza minore
    let nodoCorrente = null;
    nodiNonVisitati.forEach(nodo => {
      if (nodoCorrente === null || distanze[nodo] < distanze[nodoCorrente]) {
        nodoCorrente = nodo;
      }
    });

    if (distanze[nodoCorrente] === Infinity || nodoCorrente === fine) {
      break;
    }

    nodiNonVisitati.delete(nodoCorrente);

    // Aggiorna le distanze dei vicini
    const vicini = grafo[nodoCorrente] || {};
    for (let vicino in vicini) {
      if (nodiNonVisitati.has(vicino)) {
        let nuovaDistanza = distanze[nodoCorrente] + vicini[vicino];
        if (nuovaDistanza < distanze[vicino]) {
          distanze[vicino] = nuovaDistanza;
          precedenti[vicino] = nodoCorrente;
        }
      }
    }
  }

  // Ricostruzione del percorso a ritroso
  const percorso = [];
  let attuale = fine;
  while (attuale !== null) {
    percorso.unshift(attuale);
    attuale = precedenti[attuale];
  }

  return percorso.length > 1 || inizio === fine ? percorso : [];
}
```
