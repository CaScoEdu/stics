Add the following visual rules to the end of your `style.css` file to change the
cursor on hover and highlight a selected building with a yellow border and glow:

```diff lang="css" title="style.css"
/* Style for building text labels */
.label {
  font-size: 14px;
  font-weight: bold;
  fill: #ffffff;
  text-anchor: middle;
  dominant-baseline: middle;
  pointer-events: none;
}
- /* Add the following at the end of the file */
+ /* Hover effect for all building groups */
+ #layer-edifici > g {
+   cursor: pointer;
+   transition: opacity 0.2s ease;
+ }
+ #layer-edifici > g:hover {
+   opacity: 0.85;
+ }
+ /* Style applied by JavaScript to the SELECTED building */
+ .active rect {
+   stroke: #facc15 !important; /* Bright yellow */
+   stroke-width: 5px !important;
+   filter: drop-shadow(0px 0px 10px #facc15);
+ }
```

### 🧠 Create `script.js` and Use `document.getElementById()`


Create a new file named `script.js` in the project root folder.

In it, add a function that uses `document.getElementById()` to retrieve the SVG element
corresponding to the selected building and apply the `.active` class to it:

```javascript title="script.js"
// Called when the dropdown menu changes
function highlightBuildingFromMenu() {
    clearPreviousSelection();
    const selectMenu = document.getElementById("select-edificio");
    const idSelezionato = selectMenu.value;
    if (idSelezionato) {
        // Use getElementById to find the SVG element in the DOM
        const buildingElement = document.getElementById(idSelezionato);
        if (buildingElement) {
            buildingElement.classList.add("active");
        }
    }
}

// Called when a building on the SVG map is clicked
function selectFromMap (idEdificio) {
    const selectMenu = document.getElementById("select-edificio");
    selectMenu.value = idEdificio;
    highlightBuildingFromMenu();
}

// Helper function to clear the previous selection
function clearPreviousSelection() {
    const activeBuilding = document.querySelector(".active");
    if (activeBuilding) {
        activeBuilding.classList.remove("active");
    }
}
```

### 🎛️ Add Interactivity to `index.html`

To make the map interactive in this lesson, edit `index.html` by adding a control panel with a dropdown menu, connecting click events to the buildings, and including the external script.

<Steps>

1. #### Add a Control Panel with a Dropdown Menu (`<select>`)
    Add the control panel immediately before the `<svg>` tag.
    :::caution
    Add `<option>` elements for the buildings you have actually created in your project.
    :::

    ```diff lang="html" title="index.html"
    <h1>🗺️ Mappa del Campus Universitario</h1>
    + 
    + <!-- DROPDOWN CONTROL PANEL -->
    + <div style="margin-bottom: 15px; background: white; padding: 10px; border-radius: 8px; border: 1px solid #cbd5e1;">
    +   <label for="select-edificio"><strong>🔍 Highlight a Building:</strong></label>
    +   <select id="select-edificio" onchange="highlightBuildingFromMenu()" style="padding: 6px; border-radius: 4px; border: 1px solid #0284c7;">
    +     <option value="">-- Select a destination --</option>
    +     <option value="edificio-uffici">Administrative Offices</option>
    +     <!-- TODO: Add other buildings on your campus (e.g., classrooms, labs, etc.) -->
    +   </select>
    + </div>
    
    <svg viewBox="0 0 800 600" width="800" height="600" xmlns="http://www.w3.org/2000/svg">
    ```
2. #### Add `onclick` Events to the SVG Buildings
    To make each building respond to a mouse click, connect the
    `onclick="selectFromMap(...)"` attribute to each building's `<g>` group
    inside `<g id="layer-edifici">`.
    ```diff lang="html" title="index.html"
        <!-- LAYER 3: CAMPUS BUILDINGS -->
        <g id="layer-edifici">
    -       <g id="edificio-uffici">
    +       <!-- Add the onclick attribute linked to the JavaScript function -->
    +       <g id="edificio-uffici" onclick="selectFromMap('edificio-uffici')">
            <rect x="70" y="80" width="100" height="140" fill="#1e3a8a" rx="6" />
            <text x="120" y="150" class="label">Offices</text>
            </g>
            
    -       <!-- Repeat for the other buildings... -->
    +       <!-- TODO: Add onclick="selectFromMap('building-id')" to all other buildings in your SVG -->
        </g>
    ```
3. #### Link the External JavaScript File
    Finally, immediately before the closing body tag (`</body>`), add a reference
    to `script.js`, which contains the control logic.
    ```diff lang="html" title="index.html"

            </g>
        </g>
    </svg>
    + 
    + <!-- Link to the external JavaScript file -->
    + <script src="script.js"></script>

    </body>
    </html>
    ```

<Aside type="note" title="Key Concepts Summary" icon="puzzle">
- [`<select>` and `<option>`](https://en.wikipedia.org/wiki/HTML): create a dropdown menu for choosing a building on the map.
- [JavaScript events](https://en.wikipedia.org/wiki/JavaScript): `onchange` detects a menu selection, while `onclick` detects a click on an SVG building.
- [`document.getElementById()`](https://developer.mozilla.org/en-US/docs/Web/API/Document/getElementById): retrieves the building identified by the selected value from the DOM.
- [`classList`](https://developer.mozilla.org/en-US/docs/Web/API/Element/classList): adds or removes the `active` class to highlight the selected building.
- [`script.js`](https://developer.mozilla.org/en-US/docs/Web/JavaScript): contains the interaction logic and is linked to the HTML page.
- [CSS](https://en.wikipedia.org/wiki/CSS): defines the hover effect and the highlighting style for the `.active` class.
</Aside>
