### 🧠 Creating the `script.js` file and using `document.getElementById()`

Create a new file named `script.js` in the main project folder.

Inside it, we will add the function that uses `document.getElementById()` to retrieve the SVG element corresponding to the chosen building and apply the `.attivo` class to it:

```javascript
//script.js
// Function called when the dropdown menu changes
function highlightBuildingFromMenu() {
    removePreviousSelection();
    const selectMenu = document.getElementById("select-edificio");
    const selectedId = selectMenu.value;
    if (selectedId) {
        // use getElementById to find the SVG element in the DOM
        const buildingElement = document.getElementById(selectedId);
        if (buildingElement) {
            buildingElement.classList.add("attivo");
        }
    }
}

// Function called by clicking directly on a building in the SVG map
function selectFromMap(buildingId) {
    const selectMenu = document.getElementById("select-edificio");
    selectMenu.value = buildingId;
    highlightBuildingFromMenu();
}

// Helper function to clear the previous selection
function removePreviousSelection() {
    const activeBuilding = document.querySelector(".attivo");
    if (activeBuilding) {
        activeBuilding.classList.remove("attivo");
    }
}
```

### 🎛️ Adding interactivity in `index.html`

To make the map interactive in the second lesson, we modify the `index.html` file by inserting a control panel with a dropdown menu, linking click events to the buildings, and including the external script.

<Steps>

1. #### Inserting the control panel with the dropdown menu (`<select>`)
    Add the control panel right before the `<svg>` tag.
    :::caution
    Insert the options (`<option>`) based on the buildings you actually created in your project.
    :::

    ```diff lang="html"
    <h1>🗺️ Interactive Campus Map</h1>
    + 
    + <!-- CONTROL PANEL WITH DROPDOWN MENU -->
    + <div style="margin-bottom: 15px; background: white; padding: 10px; border-radius: 8px; border: 1px solid #cbd5e1;">
    +   <label for="select-edificio"><strong>🔍 Highlight Building:</strong></label>
    +   <select id="select-edificio" onchange="highlightBuildingFromMenu()" style="padding: 6px; border-radius: 4px; border: 1px solid #0284c7;">
    +     <option value="">-- Select a destination --</option>
    +     <option value="edificio-uffici">Administrative Offices</option>
    +     <!-- TODO: Add here the other custom buildings in your campus (e.g. Classrooms, Labs, etc.) -->
    +   </select>
    + </div>
    
    <svg viewBox="0 0 800 600" width="800" height="600" xmlns="http://www.w3.org/2000/svg">
    ```
2. #### Adding `onclick` events to the SVG buildings
    To allow each building to respond to mouse clicks,
    attach the `onclick="selectFromMap(...)"` attribute to the `<g>` groups
    of individual buildings inside `<g id="layer-edifici">`.
    ```diff lang="html"
        <!-- LAYER 3: CAMPUS BUILDINGS -->
        <g id="layer-edifici">
    -       <g id="edificio-uffici">
    +       <!-- Add the onclick attribute connected to the JavaScript function -->
    +       <g id="edificio-uffici" onclick="selectFromMap('edificio-uffici')">
            <rect x="70" y="80" width="100" height="140" fill="#1e3a8a" rx="6" />
            <text x="120" y="150" class="label">Offices</text>
            </g>
            
    -       <!-- Repeat for the other buildings... -->
    +       <!-- TODO: Extend the onclick="selectFromMap('building-id')" attribute to all other buildings in your SVG -->
        </g>
    ```
3. #### Linking the external JavaScript file
    Finally, just before the closing body tag (`</body>`),
    add the reference to the `script.js` file that will contain the control logic.
    ```diff lang="html"

            </g>
        </g>
    </svg>
    + 
    + <!-- Link to the external JavaScript file -->
    + <script src="script.js"></script>

    </body>
    </html>
    ```

<Aside type="note" title="Key Concepts Summary" icon="puzzle">
- [`<select>` and `<option>`](https://en.wikipedia.org/wiki/HTML): create a dropdown menu to choose a building on the map.
- [JavaScript events](https://en.wikipedia.org/wiki/JavaScript): `onchange` detects the menu selection and `onclick` detects the click on an SVG building.
- [`document.getElementById()`](https://developer.mozilla.org/en-US/docs/Web/API/Document/getElementById): retrieves the building identified by the selected value from the DOM.
- [`classList`](https://developer.mozilla.org/en-US/docs/Web/API/Element/classList): adds or removes the `attivo` class to highlight the selected building.
- [`script.js`](https://developer.mozilla.org/en-US/docs/Web/JavaScript): contains the interaction logic and is linked to the HTML page.
- [CSS](https://en.wikipedia.org/wiki/CSS): defines the hover effect and the highlight style for the `.attivo` class.
</Aside>
