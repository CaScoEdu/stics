## Creating `script.js` and using `document.getElementById()`

Create a new file named `script.js` in the project's root folder.

Inside it, add a function that uses `document.getElementById()`
to retrieve the SVG element corresponding to the selected building and apply the `.attivo` class:

```javascript title="script.js"
// Function invoked when the dropdown menu changes
function evidenziaEdificioDaMenu() {
    rimuoviSelezionePrecedente();
    const selectMenu = document.getElementById("select-edificio");
    const idSelezionato = selectMenu.value;
    if (idSelezionato) {
        // Use getElementById to find the SVG element in the DOM
        const elementoEdificio = document.getElementById(idSelezionato);
        if (elementoEdificio) {
            elementoEdificio.classList.add("attivo");
        }
    }
}

// Function invoked by clicking an SVG building directly on the map
function selezionaDaMappa (idEdificio) {
    const selectMenu = document.getElementById("select-edificio");
    selectMenu.value = idEdificio;
    evidenziaEdificioDaMenu();
}

// Service function to clear the previous selection
function rimuoviSelezionePrecedente() {
    const edificioAttivo = document.querySelector(".attivo");
    if (edificioAttivo) {
        edificioAttivo.classList.remove("attivo");
    }
}
```

<AsideNote title="Script explanation">
The script handles building selection in both modes.
- When the menu changes, `evidenziaEdificioDaMenu()` first removes the previous highlight, reads the selected `id`, and searches the DOM for the corresponding SVG element using `document.getElementById()`.
- If it finds the element, it adds the `.attivo` CSS class, which applies the visual effect defined in `style.css`.
- When a building is clicked on the map, `selezionaDaMappa(idEdificio)` updates the menu value and calls the same function, keeping the menu and map synchronized. `rimuoviSelezionePrecedente()` finds the element with the `.attivo` class and removes it, ensuring that only one building is highlighted at a time.
</AsideNote>

## Adding interactivity in `index.html`

To make the map interactive in the second lesson, modify `index.html` by adding a control panel with a dropdown menu, connecting click events to the buildings, and including the external script.

<Steps>
1. #### Adding the control panel with the dropdown menu (`<select>`)
    Add the control panel immediately before the `<svg>` tag.
    :::caution
    Add the `<option>` elements according to the buildings you actually created in your project.
    :::

    ```diff lang="html" title="index.html"
    <h1>🗺️ University Campus Map</h1>
    +
    + <!-- CONTROL PANEL WITH DROPDOWN MENU -->
    + <div style="margin-bottom: 15px; background: white; padding: 10px; border-radius: 8px; border: 1px solid #cbd5e1;">
    +   <label for="select-edificio"><strong>🔍 Highlight Building:</strong></label>
    +   <select id="select-edificio" onchange="evidenziaEdificioDaMenu()" style="padding: 6px; border-radius: 4px; border: 1px solid #0284c7;">
    +     <option value="">-- Select a destination --</option>
    +     <option value="edificio-uffici">Administrative Offices</option>
    +     <!-- TODO: Add the other custom buildings on your campus here (for example, classrooms and laboratories) -->
    +   </select>
    + </div>

    <svg viewBox="0 0 800 600" width="800" height="600" xmlns="http://www.w3.org/2000/svg">
    ```
2. #### Adding onclick events to SVG buildings
    To allow each building to respond to a mouse click,
    connect the `onclick="selezionaDaMappa(...)"` attribute to the `<g>` groups
    for the individual buildings inside `<g id="layer-edifici">`.
    ```diff lang="html" title="index.html"
        <!-- LAYER 3: CAMPUS BUILDINGS -->
        <g id="layer-edifici">
    -       <g id="edificio-uffici">
    +       <!-- Add the onclick attribute linked to the JavaScript function -->
    +       <g id="edificio-uffici" onclick="selezionaDaMappa('edificio-uffici')">
            <rect x="70" y="80" width="100" height="140" fill="#1e3a8a" rx="6" />
            <text x="120" y="150" class="label">Offices</text>
            </g>

    -       <!-- Repeat for the other buildings... -->
    +       <!-- TODO: Extend the onclick="selezionaDaMappa('building-id')" attribute to all other buildings in your SVG -->
        </g>
    ```
3. #### Connecting the external JavaScript file
    Finally, immediately before the closing body tag (`</body>`),
    add the reference to `script.js`, which contains the control logic.
    ```diff lang="html" title="index.html"

        </g>
    </svg>

    + <!-- Link to the external JavaScript file -->

    ```

## Summary

<KeyConcepts>
- [`<select>` and `<option>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/select): create a dropdown menu for choosing a building on the map.
- [JavaScript events](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Events): `onchange` detects a menu selection, and `onclick` detects a click on an SVG building.
- [`document.getElementById()`](https://developer.mozilla.org/en-US/docs/Web/API/Document/getElementById): retrieves from the DOM the building identified by the selected value.
- [`classList`](https://developer.mozilla.org/en-US/docs/Web/API/Element/classList): adds or removes the `attivo` class to highlight the selected building.
- [`script.js`](https://developer.mozilla.org/en-US/docs/Web/JavaScript): contains the interaction logic and is linked to the HTML page.
- [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS): defines the hover effect and the highlight style for the `.attivo` class.
</KeyConcepts>
