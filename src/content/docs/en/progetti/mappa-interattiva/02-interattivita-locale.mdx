## 📋 Requirements Analysis

<StepCard stepNumber={stepNumber++}>

### 🎯 Lesson Objective

- In this lesson, we introduce dynamic interactivity to our mapping portal: we separate the control logic into an external JavaScript file (`script.js`), add a control panel with a dropdown menu (`<select>`) for building selection, and connect interaction events (`onclick`) directly to the SVG graphics elements.
- The final output is a responsive map in which the user's choice (via the menu or a mouse click) instantly identifies and highlights the corresponding building in the DOM.

<Aside type="note" title="Expected Result">
At the end of the lesson, you will have an application where:
- the JavaScript logic is isolated in an external file (`script.js`);
- there is a dynamic dropdown menu for selecting buildings;
- users can click directly on the buildings in the SVG map to highlight them;
- the DOM is updated in real time using CSS classes and methods such as `getElementById()`.
</Aside>

</StepCard>

### 🧠 Creating `script.js` and Using `document.getElementById()`


Create a new file named `script.js` in the project's main folder.

Inside it, add the function that uses `document.getElementById()`
to retrieve the SVG element corresponding to the chosen building and apply the `.attivo` class to it:

```javascript title="script.js"
// Function called when the dropdown menu changes
function evidenziaEdificioDaMenu() {
    rimuoviSelezionePrecedente();
    const selectMenu = document.getElementById("select-edificio");
    const idSelezionato = selectMenu.value;
    if (idSelezionato) {
        // Use getElementById to find the SVG element in the DOM
        const elementoEdificio = document.getElementById(idSelezionato);
        if (elementoEdificio) {
            elementoEdificio.classList.add("attivo");
        }
    }
}

// Function called by clicking directly on a building in the SVG map
function selezionaDaMappa (idEdificio) {
    const selectMenu = document.getElementById("select-edificio");
    selectMenu.value = idEdificio;
    evidenziaEdificioDaMenu();
}

// Helper function to clear the previous selection
function rimuoviSelezionePrecedente() {
    const edificioAttivo = document.querySelector(".attivo");
    if (edificioAttivo) {
        edificioAttivo.classList.remove("attivo");
    }
}
```

### 🎛️ Adding Interactivity to index.html

To make the map interactive in this second lesson, modify `index.html` by adding a control panel with a dropdown menu, connecting click events to the buildings, and including the external script.

<Steps>

1. #### Add the control panel with the dropdown menu (`<select>`)
    Add the control panel immediately before the `<svg>` tag.
    :::caution
    Insert the `<option>` elements based on the buildings you have actually created in your project.
    :::

    ```diff lang="html" title="index.html"
    <h1>🗺️ University Campus Map</h1>
    + 
    + <!-- CONTROL PANEL WITH DROPDOWN MENU -->
    + <div style="margin-bottom: 15px; background: white; padding: 10px; border-radius: 8px; border: 1px solid #cbd5e1;">
    +   <label for="select-edificio"><strong>🔍 Highlight Building:</strong></label>
    +   <select id="select-edificio" onchange="evidenziaEdificioDaMenu()" style="padding: 6px; border-radius: 4px; border: 1px solid #0284c7;">
    +     <option value="">-- Select a destination --</option>
    +     <option value="edificio-uffici">Administrative Offices</option>
    +   <!-- TODO: Add the other custom buildings on your campus here (for example, classrooms, laboratories, etc.) -->
    +   </select>
    + </div>
    
    <svg viewBox="0 0 800 600" width="800" height="600" xmlns="http://www.w3.org/2000/svg">
    ```
2. #### Add onclick events to the SVG buildings
    To allow each building to respond to a mouse click,
    add the `onclick="selezionaDaMappa(...)"` attribute to the `<g>` groups
    for each building inside `<g id="layer-edifici">`.
    ```diff lang="html" title="index.html"
        <!-- LAYER 3: CAMPUS BUILDINGS -->
        <g id="layer-edifici">
    -       <g id="edificio-uffici">
    +       <!-- Add the onclick attribute connected to the JavaScript function -->
    +       <g id="edificio-uffici" onclick="selezionaDaMappa('edificio-uffici')">
            <rect x="70" y="80" width="100" height="140" fill="#1e3a8a" rx="6" />
            <text x="120" y="150" class="label">Offices</text>
            </g>
            
    -       <!-- Repeat for the other buildings... -->
    +       <!-- TODO: Extend the onclick="selezionaDaMappa('building-id')" attribute to all other buildings in your SVG -->
        </g>
    ```
3. #### Link the external JavaScript file
    Finally, immediately before the closing body tag (`</body>`),
    add a reference to `script.js`, which contains the control logic.
    ```diff lang="html" title="index.html"

            </g>
        </g>
    </svg>
    + 
    + <!-- Link to the external JavaScript file -->
    + <script src="script.js"></script>

    </body>
    </html>
    ```

<Aside type="note" title="Summary of Key Concepts" icon="puzzle">
- [`<select>` and `<option>`](https://it.wikipedia.org/wiki/HTML): create a dropdown menu for choosing a building on the map.
- [JavaScript Events](https://it.wikipedia.org/wiki/JavaScript): `onchange` detects a menu selection, while `onclick` detects a click on an SVG building.
- [`document.getElementById()`](https://developer.mozilla.org/it/docs/Web/API/Document/getElementById): retrieves from the DOM the building identified by the selected value.
- [`classList`](https://developer.mozilla.org/it/docs/Web/API/Element/classList): adds or removes the `attivo` class to highlight the selected building.
- [`script.js`](https://developer.mozilla.org/it/docs/Web/JavaScript): contains the interaction logic and is linked to the HTML page.
- [CSS](https://it.wikipedia.org/wiki/CSS): defines the hover effect and the highlighting style for the `.attivo` class.
</Aside>
