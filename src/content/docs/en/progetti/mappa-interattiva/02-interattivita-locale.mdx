## 2. Update `style.css` (Hover Effects and the `active` Class)

<Icon name="seti:css" size="2rem" label="css" color="DeepSkyBlue" />

At the end of your `style.css` file, add the visual rules for the hover cursor
and the highlighting effect (a yellow border and glow) when a building is selected:

```css
//style.css
/* Hover effect on all building groups */
#layer-edifici > g {
  cursor: pointer;
  transition: opacity 0.2s ease;
}
#layer-edifici > g:hover {
  opacity: 0.85;
}
/* Style applied by JavaScript to the SELECTED building */
.active rect {
  stroke: #facc15 !important; /* Bright yellow */
  stroke-width: 5px !important;
  filter: drop-shadow (0px 0px 10px #facc15);
}
```

## 3. Create `script.js` and Use `document.getElementById()`

<Icon
  name="seti:javascript"
  size="2rem"
  label="javascript"
  color="DeepSkyBlue"
/>

Create a new file named `script.js` in the project's root folder.

In it, we'll add functions that use `document.getElementById()` to retrieve the
SVG element corresponding to the selected building and apply the `.active` class:

```javascript
//script.js
// Called when the dropdown menu changes
function highlightBuildingFromMenu() {
  clearPreviousSelection();
  const selectMenu = document.getElementById("building-select");
    const idSelezionato = selectMenu.value;
    if (idSelezionato) {
        // Use getElementById to find the SVG element in the DOM
        const buildingElement = document.getElementById(selectedId);
        if (buildingElement) {
          buildingElement.classList.add("active");
        }
    }
}

// Called when a building on the SVG map is clicked directly
function selectFromMap(buildingId) {
  const selectMenu = document.getElementById("building-select");
  selectMenu.value = buildingId;
  highlightBuildingFromMenu();
}

// Helper function to clear the previous selection
function clearPreviousSelection() {
  const activeBuilding = document.querySelector(".active");
  if (activeBuilding) {
    activeBuilding.classList.remove("active");
    }
}
```

<Icon

  color="DeepSkyBlue"
