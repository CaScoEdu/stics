## 2. Updating `style.css` (Hover Effects and `attivo` Class)

<Icon name="seti:css" size="2rem" label="css" color="DeepSkyBlue" />

At the end of your `style.css` file, we add the visual rules for the cursor on mouse hover and the highlight effect (yellow border and glow) when a building is selected:

```css
//style.css
/* Hover effect on all building groups */
#layer-edifici > g {
  cursor: pointer;
  transition: opacity 0.2s ease;
}
#layer-edifici > g:hover {
  opacity: 0.85;
}
/* Style applied to the BUILDING SELECTED via JS */
.attivo rect {
  stroke: #facc15 !important; /* Bright yellow */
  stroke-width: 5px !important;
  filter: drop-shadow (0px 0px 10px #facc15);
}
```

## 2. Creating the `script.js` file and using `document.getElementById()`

<Icon
  name="seti:javascript"
  size="2rem"
  label="javascript"
  color="DeepSkyBlue"
/>

Create a new file called `script.js` in the main folder of the project.

Inside it, we add the function that uses `document.getElementById()` to get the SVG element corresponding to the selected building and apply the `.attivo` class to it:

```javascript
//script.js
// Function called when the dropdown menu changes
function evidenziaEdificioDaMenu() {
    rimuoviSelezionePrecedente();
    const selectMenu = document.getElementById("select-edificio");
    const idSelezionato = selectMenu.value;
    if (idSelezionato) {
        // we use getElementById to find the SVG element in the DOM
        const elementoEdificio = document.getElementById(idSelezionato);
        if (elementoEdificio) {
            elementoEdificio.classList.add("attivo");
        }
    }
}

// Function called when clicking directly on a building in the SVG map
function selezionaDaMappa(idEdificio) {
    const selectMenu = document.getElementById("select-edificio");
    selectMenu.value = idEdificio;
    evidenziaEdificioDaMenu();
}

// Helper function to clear the previous selection
function rimuoviSelezionePrecedente() {
    const edificioAttivo = document.querySelector(".attivo");
    if (edificioAttivo) {
        edificioAttivo.classList.remove("attivo");
    }
}
```

## 3. Updating `index.html` (Menu and JS Connection)

  color="DeepSkyBlue"

We update the `index.html` file by adding a control panel with the `<select>` dropdown, adding the `onclick` attributes to the various SVG buildings, and linking the `script.js` file before the closing `body` tag:
