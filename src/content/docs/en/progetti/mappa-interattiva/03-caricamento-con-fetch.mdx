In this lesson, we will transform our application's architecture: we will separate
the vector graphics and structured data into dedicated external files (`mappa.svg` and `locali.json`),
then load them dynamically in the browser using JavaScript's asynchronous APIs
(`fetch`, `async`, and `await`).
 
 <AsideTip title="Final output">
 The final output is a lightweight, modular page with automatically populated menus
 and a symmetrical highlighting system (starting point and destination) for both dropdown menus
 and direct map clicks.
 </AsideTip>

## Asynchronous Logic in `script.js`
We handle loading the SVG and JSON through `fetch()`
and `async/await`, connecting both the `<select>` menus
and direct clicks on the buildings in the map

```javascript title="script.js"
document.addEventListener("DOMContentLoaded", () => {
  caricaMappaSVG();
  caricaLocaliJSON();
});

async function caricaMappaSVG() {
  const risposta = await fetch("mappa.svg");
  document.getElementById("mappa-container").innerHTML = await risposta.text();
}

async function caricaLocaliJSON() {
  const risposta = await fetch("locali.json");
  const locali = await risposta.json();

  const selectDa = document.getElementById("select-da");
  const selectA = document.getElementById("select-a");

  locali.forEach(l => {
    selectDa.innerHTML += `<option value="${l.id}">${l.nome}</option>`;
    selectA.innerHTML += `<option value="${l.id}">${l.nome}</option>`;
  });
}

function aggiornaEvidenziazione() {
  const idDa = document.getElementById("select-da").value;
  const idA = document.getElementById("select-a").value;

  // Remove any previous highlighting
  document.querySelectorAll("#layer-edifici g").forEach(edificio => {
    edificio.classList.remove("selezionato-da", "selezionato-a");
  });

  // Apply the new symmetrical classes
  if (idDa) {
    document.getElementById(idDa)?.classList.add("selezionato-da");
  }
  if (idA) {
    document.getElementById(idA)?.classList.add("selezionato-a");
  }
}

function selezionaDaMappa(idEdificio) {
  const selectDa = document.getElementById("select-da");
  const selectA = document.getElementById("select-a");

  if (!selectDa.value) {
    selectDa.value = idEdificio;
  } else if (!selectA.value && selectDa.value !== idEdificio) {
    selectA.value = idEdificio;
  } else {
    selectDa.value = idEdificio;
    selectA.value = "";
  }

  aggiornaEvidenziazione();
}
```

<AsideTip title="Script Explanation">
`aggiornaEvidenziazione()` reads the values of the **Starting point** and **Destination** menus, removes previous highlighting, and applies the CSS classes corresponding to the selected venues. The `?.` operator avoids an error if the SVG element with that ID does not exist.

`selezionaDaMappa(idEdificio)` handles clicks on map venues: the first click selects the starting point, and the second selects the destination. If both are already set, a new click restarts the selection. It then calls `aggiornaEvidenziazione()` to update the map. This keeps the menus and map synchronized.
</AsideTip>

## Summary

<KeyConcepts>
- [`mappa.svg`](https://en.wikipedia.org/wiki/Scalable_Vector_Graphics): separates the map graphic from the HTML file and makes it responsive with 100% width and height.
- [`fetch()`](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch): loads external files such as `mappa.svg` and `locali.json` asynchronously; learn more about [asynchronous programming](https://en.wikipedia.org/wiki/Asynchrony_(computer_programming)).
- [`async` / `await`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/async_function): waits for requests to complete before using the data or inserting content into the DOM.
- [`locali.json`](https://www.json.org/json.html): contains the list of buildings with `id` and `nome`, useful for populating the dropdown menus; JSON stands for [JavaScript Object Notation](https://en.wikipedia.org/wiki/JSON).
- [`innerHTML`](https://developer.mozilla.org/en-US/docs/Web/API/Element/innerHTML): inserts the loaded SVG markup into the page's HTML container, in the [DOM](https://en.wikipedia.org/wiki/Document_Object_Model).
- [`classList`](https://developer.mozilla.org/en-US/docs/Web/API/Element/classList): adds or removes classes such as `.selezionato-da` and `.selezionato-a` to highlight venues in the [DOM](https://en.wikipedia.org/wiki/Document_Object_Model).
</KeyConcepts>
