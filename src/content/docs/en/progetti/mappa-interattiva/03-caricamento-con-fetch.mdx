## 📋 Requirements analysis

<StepCard stepNumber={stepNumber++}>

### 🎯 Lesson objective

- In this lesson, we transform our application's architecture: we separate
vector graphics and structured data into dedicated external files (`mappa.svg` and `locali.json`),
then load them dynamically in the browser using JavaScript asynchronous APIs
(`fetch`, `async`, and `await`).

- The final output is a lightweight, modular page with automatically populated menus
and a symmetric highlighting system (origin and destination) for both dropdown menus
and direct clicks on the map.

<Aside type="note" title="Expected result">
At the end of the lesson, you will have an application where:
- the SVG graphics are externalized and responsive;
- location data is read from an external JSON file;
- the selection menus populate automatically at startup;
- origin and destination selections visually highlight buildings on the map.
</Aside>

### ⚙️ Asynchronous Logic in `script.js`
Manage SVG and JSON loading with `fetch()`
and `async/await`, connecting both the `<select>` menus
and direct clicks on map buildings

```javascript title="script.js"
document.addEventListener("DOMContentLoaded", () => {
  caricaMappaSVG();
  caricaLocaliJSON();
});

async function caricaMappaSVG() {
  const risposta = await fetch("mappa.svg");
  document.getElementById("mappa-container").innerHTML = await risposta.text();
}

async function caricaLocaliJSON() {
  const risposta = await fetch("locali.json");
  const locali = await risposta.json();

  const selectDa = document.getElementById("select-da");
  const selectA = document.getElementById("select-a");

  locali.forEach(l => {
    selectDa.innerHTML += `<option value="${l.id}">${l.nome}</option>`;
    selectA.innerHTML += `<option value="${l.id}">${l.nome}</option>`;
  });
}

function aggiornaEvidenziazione() {
  const idDa = document.getElementById("select-da").value;
  const idA = document.getElementById("select-a").value;

  // Remove any previous highlighting
  document.querySelectorAll("#layer-edifici g").forEach(edificio => {
    edificio.classList.remove("selezionato-da", "selezionato-a");
  });

  // Apply the new symmetric classes
  if (idDa) {
    document.getElementById(idDa)?.classList.add("selezionato-da");
  }
  if (idA) {
    document.getElementById(idA)?.classList.add("selezionato-a");
  }
}

function selezionaDaMappa(idEdificio) {
  const selectDa = document.getElementById("select-da");
  const selectA = document.getElementById("select-a");

  if (!selectDa.value) {
    selectDa.value = idEdificio;
  } else if (!selectA.value && selectDa.value !== idEdificio) {
    selectA.value = idEdificio;
  } else {
    selectDa.value = idEdificio;
    selectA.value = "";
  }

  aggiornaEvidenziazione();
}
```

<Aside type="note" title="Key Concepts Summary" icon="puzzle">
- [`mappa.svg`](https://en.wikipedia.org/wiki/Scalable_Vector_Graphics): separates map graphics from the HTML file and makes them responsive with 100% width and height.
- [`fetch()`](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch): loads external files such as `mappa.svg` and `locali.json` asynchronously; learn more about [asynchronous programming](https://en.wikipedia.org/wiki/Asynchrony_(computer_programming)).
- [`async` / `await`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/async_function): waits for requests to complete before using data or inserting content into the DOM.
- [`locali.json`](https://www.json.org/json-en.html): contains the building list with `id` and `nome`, useful for populating dropdown menus; JSON means [JavaScript Object Notation](https://en.wikipedia.org/wiki/JSON).
- [`innerHTML`](https://developer.mozilla.org/en-US/docs/Web/API/Element/innerHTML): inserts the loaded SVG markup into the page's HTML container in the [DOM](https://en.wikipedia.org/wiki/Document_Object_Model).
- [`classList`](https://developer.mozilla.org/en-US/docs/Web/API/Element/classList): adds or removes classes such as `.selezionato-da` and `.selezionato-a` to highlight locations in the [DOM](https://en.wikipedia.org/wiki/Document_Object_Model).
</Aside>
