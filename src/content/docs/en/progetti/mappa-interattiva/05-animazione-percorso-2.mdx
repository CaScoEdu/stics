## Dijkstra's Algorithm (`dijkstra.js`)
<Aside type="tip" title="How does Dijkstra's algorithm work?">
- The algorithm starts at a source node and sets its initial distance to `0`, and the distance to every other node to `Infinity (∞)`.
- It progressively explores unvisited neighboring nodes, updating the shortest known path until it reaches the destination node.
</Aside>
Separate the algorithmic logic into its own file, `dijkstra.js`:

```javascript title="dijkstra.js"
 /**
 * Dijkstra's algorithm for finding the shortest path in a weighted graph
 */
function calcolaDijkstra(grafo, inizio, fine) {
  if (!grafo || !Object.hasOwn(grafo, inizio) || !Object.hasOwn(grafo, fine)) {
    return [];
  }

  const distanze = {};
  const precedenti = {};
  const nodiNonVisitati = new Set();

  // Initialize distances
  Object.keys(grafo).forEach(nodo => {
    distanze[nodo] = Infinity;
    precedenti[nodo] = null;
    nodiNonVisitati.add(nodo);
  });
  distanze[inizio] = 0;

  while (nodiNonVisitati.size > 0) {
    // Find the unvisited node with the shortest distance
    let nodoCorrente = null;
    nodiNonVisitati.forEach(nodo => {
      if (nodoCorrente === null || distanze[nodo] < distanze[nodoCorrente]) {
        nodoCorrente = nodo;
      }
    });

    if (distanze[nodoCorrente] === Infinity || nodoCorrente === fine) break;

    nodiNonVisitati.delete(nodoCorrente);

    // Update the distances of neighboring nodes
    const vicini = grafo[nodoCorrente] || {};
    for (let vicino in vicini) {
      if (nodiNonVisitati.has(vicino)) {
        let nuovaDistanza = distanze[nodoCorrente] + vicini[vicino];
        if (nuovaDistanza < distanze[vicino]) {
          distanze[vicino] = nuovaDistanza;
          precedenti[vicino] = nodoCorrente;
        }
      }
    }
  }

  // Reconstruct the path backwards
  const percorso = [];
  let at = fine;
  while (at !== null && at !== undefined) {
    percorso.unshift(at);
    at = precedenti[at];
  }

  return percorso[0] === inizio ? percorso : [];
}
```

## Update `script.js`

Overview of the logic and route-drawing functions
-   `aggiornaEvidenziazione()` (updated):

  This is the interaction's central engine.
  It runs whenever the user selects a starting point or destination:
  - clears old marks from the map,
  - applies visual classes to the menus and buildings,
  - asynchronously loads `grafo.json` using `fetch()`,
  - calls **Dijkstra's algorithm** to calculate the shortest path, then draws the line.

- `selezionaDaMappa(idEdificio)`:

  Lets the user interact directly with the SVG map by clicking buildings instead of using the dropdown menus. It handles selections intelligently: the first click sets the starting point, the second sets the destination, and subsequent clicks start over by clearing the previous selection.

- `ottieniCoordinateNodo(idNodo)`:

  An essential geometric helper function.
  It queries the SVG map DOM to find the element matching a given ID
  (whether it is a circle with a `<circle>` tag or a rectangle with a `<rect>` tag),
  reads its positional attributes, calculates its exact center, and returns the x and y coordinates ready to be drawn.

- `disegnaPercorsoAnimato(nodi)`:

  Takes the array of node IDs calculated by Dijkstra, converts each one into real coordinates using the previous function, and dynamically creates an SVG graphic element as a `<polyline>` tag. It inserts it precisely into the DOM (just below the buildings layer) to show the route on the map.

- `rimuoviSelezioniPrecedenti()`:

  The cleanup (reset) function. Before calculating and displaying a new route, it removes highlighting CSS classes from previously selected buildings and removes any previously drawn polyline from the DOM, preventing visual overlap.

<AsideNote title="🐍 The animated dotted-line effect">

The animated dotted-line effect (or moving-trail effect) uses a clever technique that manipulates the dashes of an SVG line with CSS.

Here's how it works:

1. `stroke-dasharray: 12, 12;`: This property turns a continuous line into a regular dashed line, alternating 12-pixel dashes and 12-pixel gaps (for a total pattern length of 24 pixels).

2. `stroke-dashoffset`: This property determines the starting point of the dash pattern along the line.

3. The `@keyframes` animation: by continuously and linearly (`infinite`) changing `stroke-dashoffset` from `24` to `0`, the dashes move forward along the route.

To the human eye, this continuous movement of the dashes creates the familiar optical illusion of a moving flow (like "marching ants" or an animated navigation route).
</AsideNote>

## Summary

<KeyConcepts>
- [`grafo.json`](https://en.wikipedia.org/wiki/Graph_(discrete_mathematics)): represents the campus network as nodes and weighted edges; weights indicate distances or travel costs.
- [Dijkstra's algorithm](https://en.wikipedia.org/wiki/Dijkstra%27s_algorithm): finds the shortest path between a starting point and a destination in a graph with non-negative weights.
- [`dijkstra.js`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules): contains the shortest-path algorithm, separate from the interface logic.
- [`fetch()`](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) and [`async` / `await`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/async_function): asynchronously load `grafo.json` before calculating the route.
- [SVG coordinates](https://developer.mozilla.org/en-US/docs/Web/SVG/Attribute): the `cx`, `cy`, `x`, and `y` attributes are used to find node positions on the map.
- [`<polyline>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Element/polyline) and [CSS animations](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_animations/Using_CSS_animations): draw and animate the route's dotted line.
- [`classList`](https://developer.mozilla.org/en-US/docs/Web/API/Element/classList): adds or removes highlighting classes for the starting point and destination.
</KeyConcepts>
