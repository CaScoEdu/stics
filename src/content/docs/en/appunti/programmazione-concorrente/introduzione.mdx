## Why Concurrent Programming Is Important

[**Concurrent programming**](https://en.wikipedia.org/wiki/Concurrent_computing) allows a program to manage multiple tasks within the same interval of time. Tasks can take turns or, if multiple **processors** are available, can proceed truly in parallel. This helps make better use of **resources** and keeps programs responsive while some operations are waiting, for example for data from the network.

It is used in many contexts:
- **Servers and web services**: to handle multiple user requests without completing one before starting the next.
- **Graphical interfaces**: to keep the interface responsive while performing long operations, such as loading a file.
- **Operating systems**: to manage multiple processes and services, alternating CPU use and coordinating access to resources.
- **Network communications**: to send and receive data while other tasks continue to execute.
- **Data processing**: to divide work into tasks that can proceed concurrently when dependencies allow it.
- **Simulations and video games**: to coordinate tasks such as physics updates, input handling, and rendering.

<AsideCaution>
**Concurrency** requires coordinating activities that share data or **resources**, so that dependencies are respected and inconsistent results are avoided.
</AsideCaution>

## Concetti chiave

- **Program**: a set of instructions that describe the operations to be performed.
- **Process**: a running instance of a program, with its own state and resources.
- **Process**: a running instance of a program, with its own state and resources.
- **Thread**: a flow of execution within a process. Threads in the same process share memory and resources, but each has its own execution state.
- **Processor**: a hardware component that executes instructions; a system may have multiple processors or cores.
- **Resource**: something a process needs to do its work, such as memory, files, devices, or shared data.

Concurrency can occur at different levels:
- multiple **threads**, also called *lightweight processes*, can run within the same process (for example, in C or Java).
- Alternatively, multiple **processes** can run concurrently, each with its own memory space and resources; for example, in Python, processes can be started using the `multiprocessing` module. To communicate or coordinate, processes can use inter-process communication mechanisms.

Ad ogni modo, indipendentemente dall'implementazione, i concetti esposti in queste lezioni rimangono sempre validi

## Overlapping and Interleaving

With a **multiprocessor** system (multiple processors or cores), two processes can make progress at the same instant: their executions overlap in time (**overlapping**). With a **single processor**, [**multitasking**](https://en.wikipedia.org/wiki/Computer_multitasking) gives processes short turns on the CPU: executions alternate (**interleaving**), so only one process runs at a given instant, even if rapid switching creates the appearance of simultaneity.

## Summary

<KeyConcepts>
- [**Process**](https://en.wikipedia.org/wiki/Process_(computing)): an executing program together with its state and resources.
- [**Processor**](https://en.wikipedia.org/wiki/Central_processing_unit): the component that executes program instructions.
- [**Resource**](https://en.wikipedia.org/wiki/System_resource): a hardware or software element used by a process, such as memory, files, or input/output devices.
- [**Program**](https://en.wikipedia.org/wiki/Computer_program): a set of instructions that describes operations to perform.
- [**Concurrency**](https://en.wikipedia.org/wiki/Concurrency_(computer_science)): the management of multiple activities within the same interval of time, by alternating or executing them in parallel.
- [**Overlapping**](https://en.wikipedia.org/wiki/Parallel_computing): simultaneous progress by processes on distinct processors or cores.
- [**Interleaving**](https://en.wikipedia.org/wiki/Concurrent_computing): alternation of the execution of multiple processes on a single processor.
- [**Multiprocessor**](https://en.wikipedia.org/wiki/Multiprocessing): a system with multiple processors or cores that can execute activities simultaneously.
- [**Coordination**](https://en.wikipedia.org/wiki/Concurrency_(computer_science)): management of dependencies and shared access to data or resources to prevent inconsistent results.
</KeyConcepts>
