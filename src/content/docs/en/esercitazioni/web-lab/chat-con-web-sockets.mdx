Here is a practical, complete exercise
for creating a **real-time mini chat / bulletin board**
with [**WebSocket**](https://en.wikipedia.org/wiki/WebSocket) and **Node.js**,
using the lightweight `ws` library and a native [**HTML**](https://en.wikipedia.org/wiki/HTML)/[**JavaScript**](https://en.wikipedia.org/wiki/JavaScript) page (without additional frameworks).

Unlike a classic [**HTTP**](https://en.wikipedia.org/wiki/Hypertext_Transfer_Protocol) request (where the client asks and the server responds once), a **WebSocket** opens a **persistent, bidirectional connection**: both the server and connected clients can send messages at any time.

<AsideTip title="How the connection is established: HTTP Upgrade over TCP">
The connection starts on a regular [**TCP**](https://en.wikipedia.org/wiki/Transmission_Control_Protocol) socket: the client sends an **HTTP/1.1 `GET`** request with the `Upgrade: websocket` and `Connection: Upgrade` headers (along with `Sec-WebSocket-Key` for the handshake). If the server supports WebSockets, it responds with **`101 Switching Protocols`** and `Upgrade: websocket`: from that point onward, the same TCP connection remains open and is reused to exchange bidirectional WebSocket frames, avoiding HTTP overhead for every message.
</AsideTip>

**Exercise architecture**
- **Server** (`server.js`): starts a WebSocket server on port `8080`, listens for `connection`, `message`, and `close` events, and **broadcasts** each received message to all currently connected clients.

- **Client** (`index.html`): connects to `ws://localhost:8080`, displays the connection status, sends typed messages, and updates the list in real time when new messages arrive.

3. ### Write the WebSocket server (server.js):
    
    Create the server.js file with the following code.
    
    Every new client is added to wss.clients, allowing the server to send messages to all active users.  
      
    The `server.js` file creates a **WebSocket server** in Node.js on port `8080` using the `ws` library and **broadcasts** received messages to all connected clients.

    Here's how it works step by step:

    ##### 3.1. Importing and starting the server

    * `import { WebSocketServer, WebSocket } from 'ws';` imports the class used to create the WebSocket server and the constants/types from the `ws` library.
    * `const PORT = 8080;` sets the port on which the server listens.
    * `const wss = new WebSocketServer({ port: PORT });` starts the WebSocket server on port `8080` and prints a confirmation message to the console.

    ```javascript title="server.js"
    import { WebSocketServer, WebSocket } from 'ws';

    const PORT = 8080;
    const wss = new WebSocketServer({ port: PORT });

    console.log(`WebSocket server listening on ws://localhost:${PORT}`);
    ```

    ##### 3.2. Handling a new connection (`connection`)

    Whenever a client (for example, a browser tab that opens `index.html`) connects to `ws://localhost:8080`, `wss.on('connection', (socket, req) => { ... })` runs:

    * `req.socket.remoteAddress` retrieves the client's address and `wss.clients.size` indicates how many clients are currently active.
    * `socket.send(...)` sends **only to that client** a JSON message with `type: 'system'` confirming that the connection is active.

    ```javascript title="server.js"
    /* ...  */

    wss.on('connection', (socket, req) => {
        const clientIp = req.socket.remoteAddress;
        console.log(`New client connected (${clientIp}). Active clients: ${wss.clients.size}`);

        socket.send(
            JSON.stringify({
                type: 'system',
                text: 'WebSocket connection established with the server.'
            })
        );
    ```

    ##### 3.3. Receiving and broadcasting messages (`message`)

    When a client sends data, `socket.on('message', (rawData) => { ... })` is triggered:

    * `rawData.toString().trim()` converts the received data into text and removes extra whitespace; an empty message (`!messageText`) is ignored.
    * A JSON object (`payload`) is built with:
    * `type: 'chat'` to distinguish it from system messages;
    * `text` containing the message text;
    * `timestamp` containing the local time (`en-US`).
    * The `for (const client of wss.clients)` loop checks all connected clients and sends the `payload` only to those with `client.readyState === WebSocket.OPEN` (an actually open connection).

    ```javascript title="server.js"
    /* ...  */

        socket.on('message', (rawData) => {
            const messageText = rawData.toString().trim();
            if (!messageText) return;

            console.log(`Message received: ${messageText}`);

            const payload = JSON.stringify({
                type: 'chat',
                text: messageText,
                timestamp: new Date().toLocaleTimeString('en-US')
            });

            for (const client of wss.clients) {
                if (client.readyState === WebSocket.OPEN) {
                    client.send(payload);
                }
            }
        });
    ```

    ##### 3.4. Closure and errors (`close` and `error`)

    * `socket.on('close', ...)` runs when a client closes the tab or loses its connection and updates the console with the number of active clients.
    * `socket.on('error', ...)` catches errors on an individual socket so a connection problem does not block the server.

    ```javascript title="server.js"
    /* ...  */

        socket.on('close', () => {
            console.log(`Client disconnected. Active clients: ${wss.clients.size}`);
        });

        socket.on('error', (err) => {
            console.error('Socket error:', err.message);
        });
    });
    ```

4.  ### Create the HTML/JS client (index.html):

    ##### 4.1. Header (`<head>`) and metadata
    Opens the HTML5 document in English, sets UTF-8 encoding, adapts the scale to mobile devices through the viewport, and defines the browser tab title.    
    
    ```html title"index.html"
    <!DOCTYPE html>

    <html lang="en">
        <head>
            <meta charset="UTF-8" />
            <meta name="viewport" content="width=device-width, initial-scale=1.0" />
            <title>Lab WebSocket con Node.js</title>
        </head>
    ```
    ##### 4.2. Internal style sheet (`<style>` inside `<head>`)
    Defines the centered bulletin board layout, scrollable message area (`#messages`), visual distinction between chat messages (`.msg`) and system notices (`.sys`), and the disabled send-button state.
    
    <TocAsideHint />

    ```diff lang="html" title"index.html"

    +       <style>
    +           body { font-family: system-ui, sans-serif; max-width: 640px; margin: 2rem auto; padding: 0 1rem; }
    +           #status { font-weight: 600; margin-bottom: 1rem; }
    +           #messages { border: 1px solid #cbd5e1; border-radius: 8px; padding: 1rem; height: 280px; overflow-y: auto; margin-bottom: 1rem; background: #f8fafc; }
    +           .msg { margin-bottom: 0.5rem; padding: 0.4rem 0.6rem; border-radius: 6px; background: #ffffff; border: 1px solid #e2e8f0; }
    +           .sys { color: #475569; font-style: italic; background: #f1f5f9; }
    +           form { display: flex; gap: 0.5rem; }
    +           input { flex: 1; padding: 0.6rem; border: 1px solid #94a3b8; border-radius: 6px; }
    +           button { padding: 0.6rem 1rem; border: none; border-radius: 6px; background: #2563eb; color: #fff; cursor: pointer; }
    +           button:disabled { background: #94a3b8; cursor: not-allowed; }
    +       </style>

        </head>
    ```

    ##### 4.3. Page structure (`<body>`)
    Creates the application's minimal interface: a title, the `#status` box for connection state, the `#messages` container for incoming messages, and the `#chat-form` with a text field and Send button (initially disabled until the WebSocket connects).
    
    ```html title"index.html"
        <body>

            <h1>Real-Time Bulletin Board (WebSocket)</h1>
            <div id="status">Status: connecting...</div>
            <div id="messages"></div>

            <form id="chat-form">
                <input id="msg-input" type="text" placeholder="Write a message..." autocomplete="off" required />
                <button id="send-btn" type="submit" disabled>Send</button>
            </form>
    ```

    ##### 4.4. Script — DOM references, WebSocket connection, and rendering function
    Retrieves the page's key elements, opens the connection to `ws://localhost:8080` through the native WebSocket API, and defines `appendMessage()` to add an element to the container and automatically scroll the chat downward.
    ```html title"index.html"

            <script>
                const statusEl = document.getElementById('status');
                const messagesEl = document.getElementById('messages');
                const formEl = document.getElementById('chat-form');
                const inputEl = document.getElementById('msg-input');
                const sendBtn = document.getElementById('send-btn');

                const socket = new WebSocket('ws://localhost:8080');

                function appendMessage(htmlContent, isSystem = false) {
                    const div = document.createElement('div');
                    div.className = isSystem ? 'msg sys' : 'msg';
                    div.innerHTML = htmlContent;
                    messagesEl.appendChild(div);
                    messagesEl.scrollTop = messagesEl.scrollHeight;
                }
    ```
    ##### 4.5. Script — Handling socket events (open, message, close, error)
    Reacts to WebSocket channel changes: enables the button on `open`, decodes the JSON received from the server and displays it (`message`), disables sending on `close`, and reports connection anomalies (`error`).
    
    ```html title"index.html"

                socket.addEventListener('open', () => {
                    statusEl.textContent = 'Status: connected to ws://localhost:8080';
                    sendBtn.disabled = false;
                });

                socket.addEventListener('message', (event) => {
                    const data = JSON.parse(event.data);
                    if (data.type === 'system') {
                        appendMessage(data.text, true);
                        return;
                    }
                    appendMessage(`<strong>[${data.timestamp}]</strong> ${escapeHtml(data.text)}`);
                });

                socket.addEventListener('close', () => {
                    statusEl.textContent = 'Status: disconnected from server';
                    sendBtn.disabled = true;
                });

                socket.addEventListener('error', () => {
                    statusEl.textContent = 'Status: connection error';
                });
    ```
    ##### 4.6. Script — Form submission, sanitization (`escapeHtml`), and closing the document
    Intercepts form submission to prevent a page reload, verifies that the text is non-empty and that the socket is in `WebSocket.OPEN` state, sends the message, and clears the input. `escapeHtml()` neutralizes special characters before inserting text into HTML; the script and body elements are then closed.

    ```html title"index.html"

                formEl.addEventListener('submit', (event) => {
                    event.preventDefault();
                    const text = inputEl.value.trim();
                    if (!text || socket.readyState !== WebSocket.OPEN) return;

                    socket.send(text);
                    inputEl.value = '';
                    inputEl.focus();
                });

                function escapeHtml(str) {
                    return str
                        .replaceAll('&', '&amp;')
                        .replaceAll('<', '&lt;')
                        .replaceAll('>', '&gt;')
                        .replaceAll('"', '&quot;');
                }
            </script>
        </body>
    </html>
    ```
</Steps>

## Summary

<KeyConcepts>
- [WebSocket](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API): a persistent, bidirectional communication protocol between client and server over a single connection.
- [Node.js](https://en.wikipedia.org/wiki/Node.js): a server-side JavaScript runtime used here to host the WebSocket server.
- `WebSocketServer` (`ws`): a class from the `ws` library that listens for incoming connections and manages `wss.clients`.
- `broadcast`: sending a message received from one client to every other currently connected, open client.
- `readyState` (`WebSocket.OPEN`): a property that indicates the current connection state before sending data with `send()`.
- `connection`, `open`, `message`, `close`, and `error` events: handlers that react to socket opening, data exchange, closure, or errors.
- [JSON](https://en.wikipedia.org/wiki/JSON): a text format used to structure system and chat messages (`type`, `text`, `timestamp`).
- [DOM](https://en.wikipedia.org/wiki/Document_Object_Model): the HTML page structure updated dynamically when new messages arrive.
</KeyConcepts>
