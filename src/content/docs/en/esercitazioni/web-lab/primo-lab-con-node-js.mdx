Before building the real-time chat with **WebSocket** and `ws`, it's useful to check that [**Node.js**](https://en.wikipedia.org/wiki/Node.js) works correctly on your computer and see how JavaScript runs on the server rather than inside a browser tab.

<AsideTip title="What is Node.js?">
[**Node.js**](https://en.wikipedia.org/wiki/Node.js) is an open-source runtime environment that lets you run **JavaScript** code outside the browser—for example, on a server or directly on your computer. It is based on Google's V8 engine and includes built-in modules for working with files, networks, and the operating system.
</AsideTip>

Unlike scripts running in a browser—which interact with the `DOM` and `window`—a **Node.js** script runs directly in the operating system's runtime and can access built-in modules such as `node:os`.

<AsideTip title="Why start with a minimal Node.js script?">
Running a small script first lets you check that `node` is installed, get comfortable with the terminal, and use `"type": "module"` with `import` syntax before handling network connections and events in `server.js`.
</AsideTip>

## Step-by-step instructions

<Steps>

1. **Create the folder and initialize the project**

    Open the terminal in Visual Studio Code and run:

   ```bash
   node -v
   mkdir lab-node-intro
   cd lab-node-intro
   npm init -y
   ```

2. Enable ES modules in package.json

    Make sure `"type": "module"` appears only once in `package.json`, so you can use the standard `import` syntax instead of the older `require()` (CommonJS).

3. Create and run app.js
    Create the `app.js` file with the code below:
    
    ```javascript title="app.js"
    import os from 'node:os';

    const username = os.userInfo().username;
    const platform = `${os.platform()} (${os.arch()})`;
    const currentTime = new Date().toLocaleTimeString('en-US');

    console.log(`Hello ${username}! Node.js is running on ${platform} at ${currentTime}.`);  ```
    ```
    Then run it from the terminal:
    ```bash
   node app.js
   ```
4. You will see output like this in the terminal:
    ```text
    Hello yourName! Node.js is running on win32 (x64) at 5:49:10 PM.
    ```

    <AsideTip title="What the terminal message means">
    - **`yourName`**: the name of the user currently signed in to the computer, read from `os.userInfo().username`.
    - **`win32 (x64)`** *(or `linux (x64)` / `darwin (arm64)`)*: the operating system (`os.platform()`, where `win32` identifies Windows, `darwin` macOS, and `linux` Linux) and the processor architecture (`os.arch()`, such as `x64` for 64-bit processors or `arm64` for Apple Silicon/ARM).
    - **`5:49:10 PM`**: the computer's local time when the script runs, formatted according to US English conventions (`en-US`).
    </AsideTip>
</Steps>
