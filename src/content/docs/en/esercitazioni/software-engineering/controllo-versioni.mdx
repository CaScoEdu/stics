## 👤 Create a GitHub Account
Register your developer profile:

<Steps>
1. Go to [github.com](https://github.com) and click **Sign up**.
2. Enter your email address, create a secure password, and choose a username.
3. Complete the verification and enter the confirmation code you received by email.
</Steps>

## ⚙️ Install and Configure Git
An essential prerequisite for managing files locally.

### 💾 Installation
Download and install Git from the official website [git-scm.com](https://git-scm.com)
(you can accept the default options in the setup wizard).

### 🪪 Configure Your Name and Email
Open a terminal (or the integrated VS Code terminal) and run the following commands,
replacing the values with the information associated with your GitHub account:

```bash
git config --global user.name "il mio username"
git config --global user.email "email@example.com"
```
</StepCard>

## 🧑‍💻 Create a Local Project in VS Code
Set up the initial file for your website:

<Steps>
1. Open VS Code and create a new folder on your computer called `my-first-repo`.
2. Open the folder in VS Code by selecting **File > Open Folder...**.
3. Create a new file called `index.html` and add this starter code:

    ```html
    // index.html
    <!DOCTYPE html>
    <html lang="it">
    <head>
        <meta charset="UTF-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
        <title>Mio Primo Progetto</title>
    </head>
    <body>
        <h1>Hello World</h1>
    </body>
    </html>
    ```
</Steps>
</StepCard>

## 🚀 Initialize and Publish to GitHub
Stage, commit, and publish your project to the cloud.
VS Code lets you manage the Git workflow
using a fully graphical and intuitive interface:

<Steps>
1. Click the **Source Control** icon in the left-hand
sidebar (or use the shortcut `Ctrl+Shift+G` on Windows/Linux or
`Cmd+Shift+G` on Mac).
2. Click **Initialize Repository**.
3. **Stage your changes:** Hover over `index.html` in the *Changes* list and click
the **`+`** button (**Stage Changes**). The file will move to the
*Staged Changes* section.
4. Enter a commit message in the text field at the top (e.g., `First commit: Hello World`)
and click **Commit**.
5. Click **Publish Branch**.
6. If prompted, authorize VS Code to access your GitHub account
and select **Publish to GitHub public repository**.
</Steps>
</StepCard>

## 🌿 Work with Branches: Italian vs. English
---
Complete workflow: **`Edit → Stage → Commit`** on separate branches.
Branches let you develop in parallel without affecting the main branch (`main`).
<Steps>
1. ### Branch for the `italian-version`

    - Click `main` in the bottom-left corner of the VS Code status bar.
    - Select **Create new branch...**, enter `italian-version`, and press **Enter**.
    - In `index.html`, change the heading text inside the `<h1>` tag:

    ```diff lang="html"

    -<h1>Hello World</h1>
    +<h1>Ciao Mondo</h1>
    ```

    - **Stage:** In the _Source Control_ view, click the **`+`** next to `index.html` to stage the change.
    - **Commit & Publish:** Enter the message `Italian translation`, click **Commit**, then click **Publish Branch**.

2. ### Branch for the `english-version`

    - Return to the main branch: click `italian-version` in the bottom-left corner and select `main` from the list. Notice that `index.html` returns to its original version!
    - Create a new branch called `english-version` using the same procedure.
    - Add a detail in English to `index.html`:
    ```diff lang="html"
    <h1>Hello World</h1>
    +<p>Welcome to my first versioned website!</p>
    ```
    - **Stage:** Click the **`+`** next to `index.html` to stage the changes.
    - **Commit & Publish:** Enter the message `Update English version`, click **Commit**, then **Publish Branch**.
</Steps>
</StepCard>

<StepCard stepNumber={stepNumber++}>
## 🔍 Verify That the Branches Are Different
To see the real "magic" of Git and confirm that both versions coexist in the same project without overwriting each other, follow these steps:

### 💻 Locally in VS Code:
<Steps>
1. Click the branch name in the bottom-left corner of the VS Code status bar.
2. Select `italian-version`: look at `index.html` in the editor and you will see the text _"Ciao Mondo"_.
3. Click again and select `english-version`: the file will instantly change to show _"Hello World"_ and the new paragraph.
</Steps>

### ☁️ On GitHub:
<Steps>
1. Open your repository on [github.com](https://github.com).
2. Above the file list in the top-left, click the dropdown showing `main` (or _Branches_).
3. Select `italian-version` or `english-version` to browse the branches: the code in `index.html` will change instantly depending on the selected branch!
</Steps>
</StepCard>

<Aside type="note" title="Key Concepts Summary" icon="puzzle">
- [Git](https://en.wikipedia.org/wiki/Git) is a distributed version control system.
- [GitHub](https://en.wikipedia.org/wiki/GitHub) is an online platform for sharing and collaborating on Git repositories.
- [Repository](https://en.wikipedia.org/wiki/Repository_(version_control)) is the container for the project and its history.
- [Branch (software development)](https://en.wikipedia.org/wiki/Branch_(version_control)) indicates a parallel development line from the main branch.
- [Version control](https://en.wikipedia.org/wiki/Version_control) is the practice of tracking and managing changes over time.
- [Commit](https://en.wikipedia.org/wiki/Commit_(version_control)) represents a saved revision of the project.
</Aside>
