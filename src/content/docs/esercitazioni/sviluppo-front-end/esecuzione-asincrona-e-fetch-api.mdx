## 1. Il codice essenziale `index.html`
<IconGroup techIconList={["vscode","seti:html"]} />

Creiamo un file `index.html`  e un file `hello.txt` nella stessa cartella:
</Card>

<Tabs>

<TabItem label="index.html" icon="seti:html" >
```html
<!DOCTYPE html>
<html lang="it">
<head>
    <meta charset="UTF-8">
    <title>Intro Async Fetch</title>
</head>
<body>

    <button onclick="caricaMessaggio()">Carica "Hello World"</button>

    <!-- Contenitore minimale dove stampare il testo -->
    <div id="output">In attesa del click...</div>

    <script>
    // 1. 'async' rende la funzione asincrona
    async function caricaMessaggio() {
        const output = document.getElementById('output');

        try {
        // 2. 'await fetch' scarica la risorsa in modo non bloccante
        const response = await fetch('hello.txt');

        // 3. Controllo se il file è stato trovato (es. 200 OK)
        if (!response.ok) {
            throw new Error('File non trovato!');
        }

        // 4. 'await' attende la conversione del corpo della risposta in testo
        const testo = await response.text();

        // 5. Inseriamo il testo nel DOM (senza alert)
        output.textContent = testo;

        } catch (errore) {
        // Gestione di eventuali problemi di rete o file mancanti
        output.textContent = 'Errore: ' + errore.message;
        }
    }
    </script>

</body>
</html>
```
</TabItem>
<TabItem label="hello.txt" icon="document">
```txt

```
</TabItem>
