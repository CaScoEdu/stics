Impara a gestire l'esecuzione asincrona in JavaScript e a recuperare dati da servizi web con la Fetch API.

## Introduzione

<ExpectedResults title="Risultati attesi">
- il contenuto di `hello.txt` viene richiesto al server con `fetch()`;
- l'attesa della risposta e della lettura del testo è gestita con `async` e `await`;
- il risultato viene controllato tramite `response.ok` e mostrato nel DOM;
- gli errori vengono intercettati con `try/catch` e comunicati all'utente.
</ExpectedResults>

<Prerequisites title="Prerequisiti">
- saper creare e modificare file HTML e JavaScript
- conoscere le variabili, le funzioni e l'uso del DOM
- sapere aprire una pagina nel browser e usare gli strumenti di sviluppo
- avere accesso a Internet per usare eventuali servizi online o risorse esterne
</Prerequisites>

## Codifica

Qui nel seguito il contenuto dei due file:

<Tabs>

<TabItem label="index.html" icon="seti:html" >
```html
<!DOCTYPE html>
<html lang="it">
<head>
    <meta charset="UTF-8">
    <title>Intro Async Fetch</title>
</head>
<body>

    <button onclick="caricaMessaggio()">Carica "Hello World"</button>

    <!-- Contenitore minimale dove stampare il testo -->
    <div id="output">In attesa del click...</div>

    <script>
    // 1. 'async' rende la funzione asincrona
    async function caricaMessaggio() {
        const output = document.getElementById('output');

        try {
        // 2. 'await fetch' scarica la risorsa in modo non bloccante
        const response = await fetch('hello.txt');

        // 3. Controllo se il file è stato trovato (es. 200 OK)
        if (!response.ok) {
            throw new Error('File non trovato!');
        }

        // 4. 'await' attende la conversione del corpo della risposta in testo
        const testo = await response.text();

        // 5. Inseriamo il testo nel DOM (senza alert)
        output.textContent = testo;

        } catch (errore) {
        // Gestione di eventuali problemi di rete o file mancanti
        output.textContent = 'Errore: ' + errore.message;
        }
    }
    </script>

</body>
</html>
```
</TabItem>
<TabItem label="hello.txt" icon="document">
```txt
Hello World!
```
</TabItem>
</Tabs>

In sintesi, il codice usa `async` e `await` per rendere la richiesta non bloccante: 
- `fetch('hello.txt')` avvia una richiesta [HTTP](https://it.wikipedia.org/wiki/Hypertext_Transfer_Protocol), 
- `response.ok` verifica che la risposta sia riuscita 
- e `response.text()` legge il contenuto del file come testo.
- Il blocco `try/catch` gestisce eventuali errori di rete o file non trovato, evitando che la pagina si blocchi e permettendo di aggiornare il [DOM](https://it.wikipedia.org/wiki/Document_Object_Model) con il risultato.

## Riepilogo

<KeyConcepts title="Concetti chiave">
- [Esecuzione asincrona](https://it.wikipedia.org/wiki/Programmazione_asincrona): permette di attendere operazioni come una richiesta di rete senza bloccare l'interfaccia.
- [Promise](https://developer.mozilla.org/it/docs/Web/JavaScript/Reference/Global_Objects/Promise): rappresenta il risultato futuro di un'operazione asincrona.
- `async` e `await`: semplificano la gestione delle Promise; `await` attende un risultato senza bloccare il browser.
- [Fetch API](https://developer.mozilla.org/it/docs/Web/API/Fetch_API): consente di effettuare richieste di rete e ricevere una `Response`.
- [HTTP](https://it.wikipedia.org/wiki/Hypertext_Transfer_Protocol): protocollo usato per la comunicazione tra browser e server.
- `response.ok`: indica se la risposta HTTP ha uno status compreso tra 200 e 299.
- `response.text()`: legge il corpo della risposta e lo restituisce come testo.
- [DOM](https://it.wikipedia.org/wiki/Document_Object_Model): rappresentazione della pagina che JavaScript può aggiornare.
- `try/catch`: permette di gestire gli errori che si verificano durante la richiesta o la lettura della risposta.
</KeyConcepts>
