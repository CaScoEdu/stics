## Passo 1: La Struttura HTML (`index.html`)

Iniziamo creando l'interfaccia utente. 
L'HTML definisce i pulsanti di controllo e il riquadro 
di console dove compariranno lo stato del download e il testo del diario.

```html
//index.html
<!DOCTYPE html>
<html lang="it">
<head>
  <meta charset="UTF-8">
  <title>Missione Ares-IV - Registro di Bordo</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>🚀 Missione Ares-IV: Log di Bordo</h1>
  <p>Seleziona una registrazione da scaricare dal server centrale:</p>
  
  <!-- Pulsanti di controllo -->
  <button id="btn-log1">Registro Giorno 1</button>
  <button id="btn-log2">Registro Giorno 42</button>
  <button id="btn-errore">Test Errore (404)</button>

  <!-- Console di visualizzazione -->
  <div class="console">
    <strong>Stato Connessione:</strong> <span id="stato">In attesa...</span>
    <hr>
    <div id="log">Nessun dato caricato.</div>
  </div>

  <script src="app.js"></script>
</body>
</html>
```

### Spiegazione dell'HTML
I tre pulsanti hanno ciascuno un id univoco per poter agganciare
gli eventi JavaScript da codice.
- <code>#stato</code> accoglierà i messaggi di avanzamento del caricamento
  (es. "In corso...", "Ok", "Errore").
- <code>#log</code> conterrà il testo effettivo scaricato dal file di testo.

## Passo 2: Lo Stile Grafico (<code>style.css</code>)
Creiamo un file separato <code>style.css</code> per dare alla pagina
 l'aspetto di un vero terminale di bordo. 

```css
//style.css
body {
  background-color: #0d1117;
  color: #58a6ff;
  font-family: monospace;
  padding: 20px;
}

.console {
  border: 1px solid #30363d;
  padding: 15px;
  border-radius: 6px;
  background-color: #161b22;
  margin-top: 15px;
}

button {
  background-color: #238636;
  color: white;
  border: none;
  padding: 10px 15px;
  margin-right: 8px;
  cursor: pointer;
  border-radius: 4px;
}

button:hover {
  background-color: #2ea043;
}

#log {
  margin-top: 15px;
  white-space: pre-wrap;
  color: #c9d1d9;
}
```
### Spiegazione del CSS
- <code>font-family: monospace</code> simula i font dei terminali di comando.   
- <code>white-space: pre-wrap</code> 
sul contenitore <code>#log</code> è fondamentale: fa sì che i ritorni a capo
 (<code>\n</code>) 
presenti nel file di testo vengano rispettati a schermo.

## Passo 4: La Logica JavaScript (<code>app.js</code>)
Costruiamo la logica dello script dividendola in blocchi concettuali.

### Snippet A: La dichiarazione della funzione asincrona
```javascript
// Usiamo la parola chiave 'async' per abilitare l'uso di 'await' al suo interno
async function caricaLog(nomeFile) {
const elementoStato = document.getElementById('stato');
const elementoLog = document.getElementById('log');
// Codice di caricamento...
}
```
:::tip[Spiegazione]
La parola chiave `async` indica al browser
che questa funzione eseguirà operazioni asincrone e restituirà una `Promise`.
:::

---

### Snippet B: La richiesta HTTP con `await fetch()`
```javascript
// 1. Iniziamo il blocco di controllo degli errori
try {
    elementoStato.textContent = `Download di ${nomeFile} in corso...`;
    
    // 2. Inviamo la richiesta e ATTENDIAMO gli header della risposta
    const response = await fetch(nomeFile);
    
    // 3. Verifichiamo se il file esiste sul server (es. HTTP 200 OK)
    if (!response.ok) {
    throw new Error(`File non trovato (Codice HTTP: ${response.status})`);
    }
}
```
:::tip[Spiegazione]
`await fetch()` blocca l'esecuzione interna della funzione 
finché il server non risponde, senza però bloccare la pagina web.
Se il file non esiste (es. `404`), 
`response.ok` sarà `false` e generiamo manualmente un errore con `throw`.
:::

---
### Snippet C: La conversione in testo e l'aggiornamento del DOM
```javascript
// 4. ATTENDIAMO che l'intero contenuto del file venga letto come testo
    const testo = await response.text();
    
    // 5. Aggiorniamo l'interfaccia con i dati ricevuti
    elementoStato.textContent = 'Connessione completata con successo.';
    elementoLog.textContent = testo;
    
  } catch (errore) {
    // Gestione in caso di problemi di rete o file inesistente
    elementoStato.textContent = 'ERRORE DI TRASMISSIONE!';
    elementoLog.textContent = errore.message;
  }
}
```
:::tip[Spiegazione]
`await response.text()` serve perché il corpo della risposta
arriva in streaming.
Serve un secondo `await` per completare la lettura del testo.
:::

---

### Snippet D: Collegare gli Event Listener ai Pulsanti

```javascript
// Colleghiamo la funzione ai pulsanti dell'interfaccia
document.getElementById('btn-log1').addEventListener('click', () => caricaLog('log1.txt'));
document.getElementById('btn-log2').addEventListener('click', () => caricaLog('log2.txt'));
document.getElementById('btn-errore').addEventListener('click', () => caricaLog('log-inesistente.txt'));
```

Riferimento: [`CORS`](https://en.wikipedia.org/wiki/Cross-origin_resource_sharing).
Se si apre il file `index.html` facendo semplicemente doppio clic

Ricordati di eseguire il progetto tramite un server locale
